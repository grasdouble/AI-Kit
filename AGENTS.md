# Repository guidance

This repository's `AGENTS.md` files route contributors and AI agents to artifact-specific rules. Load only the artifact-specific instructions needed for the current task; do not load unrelated guidance or duplicate its content here.

- Creating or editing skills: read [skill-authoring.md](skill-authoring.md).
- Creating or editing agent profiles: read [agent-authoring.md](agent-authoring.md).
- Creating or editing shared instructions: read [instruction-authoring.md](instruction-authoring.md).
